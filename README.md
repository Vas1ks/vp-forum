# ВП | Выживание с Подписчиками — Форум

Официальный форум проекта «ВП | Выживание с Подписчиками» — одностраничное веб-приложение (SPA) для обсуждений, новостей и предложений сообщества.

Репозиторий содержит **фронтенд и локальный бэкенд**. Данные хранятся в JSON-файле (`db.json`), внешние API не используются.

- **Discord-сообщество:** https://discord.gg/Fn6UecrNNM
- **Репозиторий:** https://github.com/Vas1ks/vp-forum

---

## Возможности

- Просмотр тем по категориям: Новости, Технический, Мероприятия, Предложения, История, Общее, Постройки
- Создание новых тем (требуется авторизация)
- Комментарии с прикреплением изображений (base64)
- Лайки на комментарии
- Счётчик просмотров тем
- Регистрация и вход (токен сохраняется в `localStorage` под ключом `vp_token`)
- Переключение светлой и тёмной темы
- Навигация по hash-роутингу (`#topic/:id`, `#profile/:nick`, `#admin`, `#account`, `#history`)
- Страница «История ВП» с шаблоном для текста и фото
- Панель администратора: управление пользователями, выдача ролей, баны

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Vas1ks/vp-forum.git
cd vp-forum
```

### 2. Установить зависимости

```bash
npm install
```

### 3. Запустить бэкенд

```bash
npm start
```

Сервер запустится на http://localhost:3001

Либо через скрипты автозапуска (запуск в фоне с логом и PID):

```bash
npm run run    # запустить бэкенд в фоне
npm run stop   # остановить бэкенд
```

Скрипт `start.sh` сам установит зависимости при необходимости, запустит
сервер отвязанно (`setsid`) и проверит доступность на порту 3001.
Логи пишутся в `server.log`, PID — в `server.pid`.

### 4. Открыть форум

Фронтенд — статический HTML. Откройте `index.html` напрямую или через локальный сервер:

```bash
python -m http.server 8080
```

После этого откройте в браузере: http://localhost:8080

## API (локальный бэкенд)

Фронтенд использует REST API. Сервер реализован в `server.js` (Express + JSON-файл).

| Метод | Путь | Назначение |
|-------|------|------------|
| `POST` | `/register` | Регистрация нового пользователя |
| `POST` | `/login` | Вход, получение токена |
| `GET` | `/topics` | Список всех тем |
| `POST` | `/topics` | Создание новой темы |
| `GET` | `/comments/:topicId` | Комментарии конкретной темы |
| `POST` | `/comments` | Добавление комментария |
| `PUT` | `/comments/:id` | Редактирование комментария |
| `DELETE` | `/comments/:id` | Удаление комментария |
| `GET` | `/likes` | Список всех лайков |
| `POST` | `/likes` | Поставить / убрать лайк |
| `GET` | `/views` | Список просмотров по темам |
| `POST` | `/views/:topicId` | Увеличить счётчик просмотров темы |
| `GET` | `/users` | Список пользователей |
| `GET` | `/users/:nick` | Профиль пользователя |
| `POST` | `/change-role/:id` | Изменение роли пользователя |
| `POST` | `/ban/:id` / `/unban/:id` | Бан / разбан |
| `GET` | `/online` / `POST /online` | Онлайн-статус |

### Авторизация

После успешного входа или регистрации сервер возвращает токен. Фронтенд сохраняет его в `localStorage` и декодирует payload для отображения ника и проверки роли.

Создание тем, комментариев и лайков доступно только авторизованным пользователям.
