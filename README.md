# ВП | Выживание с Подписчиками — Форум

Официальный форум проекта «ВП | Выживание с Подписчиками» — одностраничное веб-приложение (SPA) для обсуждений, новостей и предложений сообщества.

Репозиторий содержит **только фронтенд**. Данные хранятся и обрабатываются внешним API, развёрнутым на [Railway](https://railway.app).

- **Discord-сообщество:** https://discord.gg/Fn6UecrNNM
- **Репозиторий:** https://github.com/Vas1ks/vp-forum

---

## Возможности

- Просмотр тем по категориям: Новости, Технический, Мероприятия, Предложения, История, Общее, Постройки
- Создание новых тем (требуется авторизация)
- Комментарии с прикреплением изображений (base64)
- Лайки на комментарии
- Счётчик просмотров тем
- Регистрация и вход (JWT-токен сохраняется в `localStorage` под ключом `vp_token`)
- Переключение светлой и тёмной темы
- Навигация по hash-роутингу (`#topic/:id`)

## Быстрый старт

Проект не требует сборки и не содержит `package.json` — это чистый статический фронтенд.

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Vas1ks/vp-forum.git
cd vp-forum
```

### 2. Запустить локальный HTTP-сервер

Открытие `index.html` напрямую через `file://` может ограничить работу с API из-за политики CORS. Рекомендуется использовать локальный сервер:

```bash
python -m http.server 8080
```

После этого откройте в браузере: http://localhost:8080

Альтернативы: расширение **Live Server** в VS Code / Cursor, `npx serve`, любой другой статический HTTP-сервер.

### 3. Подключение к API

По умолчанию фронтенд обращается к удалённому бэкенду на Railway. URL задаётся в начале файла `script.js`:

```javascript
const API = "https://web-production-d1dc3.up.railway.app";
```

Чтобы переключиться на другой сервер, измените значение константы `API` и перезагрузите страницу.

> Для полной работы форума нужен доступ к работающему API. Бэкенд в этот репозиторий не входит.

## API (внешний бэкенд)

Фронтенд использует REST API. Исходный сервер (Express + PostgreSQL + JWT) разрабатывался в этом репозитории, но был **перенесён в отдельный деплой** 12.06.2026 (коммит `d8fb9c0`).

| Метод | Путь | Назначение |
|-------|------|------------|
| `POST` | `/register` | Регистрация нового пользователя |
| `POST` | `/login` | Вход, получение JWT-токена |
| `GET` | `/topics` | Список всех тем |
| `POST` | `/topics` | Создание новой темы |
| `GET` | `/comments/:topicId` | Комментарии конкретной темы |
| `POST` | `/comments` | Добавление комментария |
| `GET` | `/likes` | Список всех лайков |
| `POST` | `/likes` | Поставить / убрать лайк |
| `GET` | `/views` | Список просмотров по темам |
| `POST` | `/views/:topicId` | Увеличить счётчик просмотров темы |

### Авторизация

После успешного входа или регистрации сервер возвращает JWT-токен. Фронтенд сохраняет его в `localStorage` и декодирует payload для отображения ника и проверки роли (`user` / `admin`).

Создание тем, комментариев и лайков доступно только авторизованным пользователям.
